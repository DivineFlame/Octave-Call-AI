---
title: Fork Workflow
description: Keep your Octave-Call-AI fork connected to upstream.
---

The contributor bootstrap script configures two remotes:

- `origin`: your fork, where you push
- `upstream`: `DivineFlame/Octave-Call-AI`, where new commits land

If you cloned `DivineFlame/Octave-Call-AI` directly instead of your fork, run this once inside the devcontainer after it boots:

```bash
bash scripts/setup_fork.sh
```

To pull in upstream changes:

```bash
git fetch upstream
git checkout main
git merge upstream/main
git push origin main
```

Check your remotes any time with:

```bash
git remote -v
```

You should see:

```bash
origin    https://github.com/<YOUR_HANDLE>/octave-call-ai.git (fetch/push)
upstream  https://github.com/DivineFlame/Octave-Call-AI.git    (fetch/push)
```

<Note>
Always push feature branches to **`origin`** (your fork), then open a pull request against `DivineFlame/Octave-Call-AI:main`. Never push directly to `upstream`.
</Note>
